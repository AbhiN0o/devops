# Exercise 0: Personal Portfolio

A multi-page personal portfolio for Abhinav Sahu, built with plain HTML and CSS (no build step).

## Pages
- `index.html`: home and highlights
- `about.html`: about me
- `education.html`: education timeline
- `skills.html`: skills by category
- `projects.html`: NoteIt, TubeMind, Baskit
- `contact.html`: contact details and message form
- `style.css`: shared styles (light and dark mode)

## Run it
Open `index.html` in a browser, or run `python -m http.server` in this folder.
